# Cenizas del Nuevo Mundo

Videojuego 2D de accion, plataformas y exploracion desarrollado en Unity 6.6.

## Tecnologias
- Unity 6000.6.4f1
- Universal Render Pipeline 2D
- C#
- Input System
- Cinemachine
- Tilemap 2D

## Funcionalidades implementadas
- Movimiento, salto y combate de Jekken
- Ataque 2 y habilidad Ulti
- Sistema de salud y enemigos
- HUD de vida, Nucleos y fragmentos
- Objetos coleccionables
- Menu principal
- Cinematica inicial
- Tutorial jugable
- Sistema de dialogos y objetivos
